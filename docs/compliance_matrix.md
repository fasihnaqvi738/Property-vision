## Next engineering sequence

1. Regenerate or archive the two pre-contract RGB-D outputs if they are needed as deliverables; schema conformance does not validate geometric accuracy.
2. Use the existing photo/video paths and the manual plan as a baseline; improve room matching/reconstruction only where the supplied imagery supports it.
3. Acquire the missing iPhone/Polycam multi-room capture, staged-damage scenes, same-room repeats, laser/tape truth, and incumbent exports. These evidence requirements cannot be produced from the supplied promotional photos/video.
4. Implement and validate cross-tier room placement, metric dimensions, openings, confidence intervals, damage/scope, and drift correction on that benchmark; compare before/after for the declared fix loop.
5. Rerun the whole route on a clean machine, then finalize the technical report and reproduction bundle from the real outputs.

The order can change when benchmark evidence identifies a more important failing gate; no accuracy claim should be made before that evidence exists.
