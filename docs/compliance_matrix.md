## Next engineering sequence

1. Use the new ARKitScenes depth check as external LiDAR sensor evidence; schema conformance and per-pixel depth error do not validate room geometry.
2. Use the existing photo/video paths and the manual plan as a baseline; improve room matching/reconstruction only where the supplied imagery supports it.
3. Run the hosted damage detector on staged photos, then measure detection and quantity precision against labeled boxes or masks; collect same-room repeats, laser/tape truth, and incumbent exports for the benchmark.
4. Extend one-scan candidate stitching to shared-frame multi-room captures, resolve connector geometry, and validate room placement, metric dimensions, openings, confidence intervals, and drift correction against surveyed truth; compare before/after for the declared fix loop.
5. Rerun the whole route on a clean machine, then finalize the technical report and reproduction bundle from the real outputs.

The order can change when benchmark evidence identifies a more important failing gate; no accuracy claim should be made before that evidence exists.
